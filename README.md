# Project Overview

This project focuses on analyzing travel behaviour data using Microsoft Excel to understand travel patterns, preferences, and decision-making. The objective is to answer key analytical questions, identify problems, and interpret trends using structured data.

# What This Project Does
Analyzes travel behaviour datasets using Excel formulas and functions
Breaks down analytical questions step by step
Helps in understanding the problem statement clearly
Uses charts and graphs to visually explain patterns and insights
Makes complex data easy to understand through visual storytelling

# Tools & Techniques Used
Microsoft Excel
Data cleaning and formatting
Pivot Tables & Pivot Charts
Graphs (Bar, Line, Pie, etc.)
Basic statistical analysis

# Outcome
By combining question-based analysis with graphical representation, this project helps in understanding travel behaviour in a clear, structured, and visual manner. It demonstrates how Excel can be effectively used for real-world analytics and decision-making.
